# Trident and net equipment v001

Original native pixel artwork prepared by `prepare-equipment.mjs`. The JSON and SVG sources are editable and recorded alongside lossless PNGs and hashes. No provider jobs or new generated artwork were used. Preserved v006/v013 catalogs, heads, bodies, hands, helmets and previous equipment remain untouched. The additive manifest retains the exact v014 dagger entry.

The trident attaches to each armor's existing main hand. Its weighted net attaches to the existing offhand and replaces the decorative shield only with this weapon. Neither attachment changes a saved appearance or any body/identity transform.

Entangle is a combat technique, while these textures are presentation. The net deals low technique damage and imposes a visible +3 stamina attack surcharge for the next round. Guard prevents or clears it; Recover clears it. It expires after that round and does not stack or persist across duels.

Preparation and rendered controls establish implementation evidence. Browser review and the user's art judgment are separate.
